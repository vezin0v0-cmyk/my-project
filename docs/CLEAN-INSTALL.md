# Чистая Windows + Nova: пошагово

Лучше всего Nova работает на свежей Windows: нет старого мусора, программ-«оптимизаторов» и остатков чужих настроек. Ниже весь путь от «снести всё» до готовой системы.

Понадобится:
- флешка на **8 ГБ** или больше (всё на ней сотрётся);
- интернет;
- около **1,5–2 часов**.

---

## Шаг 1. Сохрани важное

После переустановки диск с Windows будет **полностью стёрт**. Перед этим перенеси на флешку, внешний диск или в облако:

- **Файлы**: «Рабочий стол», «Документы», «Загрузки», «Изображения», «Видео», «Музыка».
- **Пароли браузера**: войди в аккаунт браузера (Chrome, Яндекс, Firefox) и включи синхронизацию. Или экспортируй пароли в настройках браузера.
- **Сохранения игр**, которых нет в облаке Steam/Epic: обычно лежат в «Документы\My Games» и «C:\Users\Имя\AppData».
- **Ключи и логины** от платных программ.
- **Пароль от Wi-Fi**, если не помнишь его.

> Лицензию Windows сохранять не нужно. Если Windows на этом компьютере уже была активирована, после переустановки той же редакции (Home → Home, Pro → Pro) она активируется сама. Свою редакцию посмотри в «Параметры → Система → О системе → Выпуск».

## Шаг 2. Сделай установочную флешку

Используй **только официальную программу Microsoft**. Скачанные из интернета «сборки» и торренты часто содержат вирусы.

1. На любом компьютере с Windows открой https://www.microsoft.com/software-download/windows11
2. В разделе «Создание установочного носителя Windows 11» нажми **Скачать** и запусти программу (Media Creation Tool).
3. Выбери **USB-устройство флэш-памяти**, потом свою флешку. Программа сама скачает Windows и запишет её на флешку. Это занимает 20–40 минут.

Если страница Microsoft не открывается или программа пишет ошибку при загрузке, значит, в твоей стране Microsoft ограничивает скачивание. Тогда попробуй через VPN или попроси друга сделать флешку.

**Windows 11 или 10?** Ставь Windows 11. Обычная поддержка Windows 10 закончилась, и обновления безопасности для неё больше не выходят. Чтобы узнать, подходит ли компьютер, есть официальная программа «Проверка работоспособности ПК» (PC Health Check). Если не подходит, Windows 10 скачивается так же, на странице https://www.microsoft.com/software-download/windows10

## Шаг 3. Установи Windows

1. Вставь флешку и перезагрузи компьютер.
2. Сразу при включении нажимай клавишу **меню загрузки** и выбери флешку. Обычно это **F12**, **F11**, **F8** или **Esc**: зависит от материнской платы, подсказка мелькает на первом экране.
3. Выбери язык и нажми **Установить**.
4. Когда попросит ключ, нажми **«У меня нет ключа продукта»**. Выбери ту же редакцию, что была раньше.
5. Тип установки: **«Выборочная: только установка Windows»**.
6. Появится список дисков и разделов. **Будь внимателен**:
   - Удали **все разделы только того диска, где была Windows** («Диск 0», он обычно самый первый).
   - Если у тебя **два диска** (например, второй с играми и файлами), **не трогай его разделы**. Отличить диски можно по размеру.
   - Выдели «Незанятое пространство» на диске 0 и нажми **Далее**.
7. Подожди. Компьютер несколько раз перезагрузится. Если он снова загрузится с флешки, вынь её.

**Первая настройка:**
- Подключись к интернету и войди в аккаунт Microsoft, если Windows просит. Это нормально: навязчивые напоминания про аккаунт Nova потом уберёт.
- На экране **«Параметры конфиденциальности»** выключи всё. Для диагностики выбери «только обязательные».
- Где предлагают OneDrive, Microsoft 365, Xbox Game Pass и прочее, жми **«Пропустить»** или **«Нет»**.

## Шаг 4. Доведи Windows до готовности

Сделай это **до** Nova:

1. **Обновления:** «Параметры → Центр обновления Windows → Проверить наличие обновлений». Установи всё и перезагрузи. Повторяй, пока не напишет, что обновлений нет. Там же загляни в «Дополнительные параметры → Необязательные обновления»: в нём бывают драйверы.
2. **Драйвер видеокарты** скачай с официального сайта:
   - NVIDIA: nvidia.com → Драйверы (или приложение NVIDIA App);
   - AMD: amd.com → Drivers & Support;
   - Intel: intel.com → Поддержка → Драйверы.
3. **Не ставь** другие «оптимизаторы», «чистильщики» и твикеры. Они спорят с Nova за те же настройки.

## Шаг 5. Запусти Nova

1. Скачай Nova с сайта: https://vezin0v0-cmyk.github.io/my-project/docs/ → кнопка **«Скачать бесплатно»**.
2. Нажми на архив правой кнопкой → **«Свойства»** → внизу поставь галочку **«Разблокировать»** → **OK**. Так Windows не будет считать файлы «скачанными из интернета» и меньше будет мешать.
3. Снова правой кнопкой по архиву → **«Извлечь всё…»**, например на Рабочий стол. Запускать прямо из архива нельзя: Nova.cmd сам подскажет распаковать.
4. Хочешь сам выбрать настройки? В кабинете на сайте открой **конструктор**, отметь нужное, скачай **config.json** и положи его в папку Nova с заменой.
5. Дважды кликни **Nova.cmd**:
   - Windows может написать «Windows защитила ваш компьютер». Нажми **Подробнее → Выполнить в любом случае**. Так Windows реагирует на любые программы без платной цифровой подписи.
   - На вопрос «Разрешить вносить изменения?» нажми **Да**.
6. Вверху меню Nova сразу покажет **проверку системы**:
   - зелёная строка «система готова» — можно продолжать;
   - жёлтая «есть замечания» — нажми **6** и посмотри, что не так. Чаще всего Windows ждёт **перезагрузки после обновлений**: перезагрузи компьютер и запусти Nova снова;
   - красная — Nova подскажет, что исправить.
7. **1 — Посмотреть, что изменится.** Это ничего не меняет, только показывает план.
8. **2 — Применить.** Nova создаст точку восстановления, запомнит, как было, и применит настройки.
9. **Перезагрузи компьютер.**
10. Снова открой Nova и выбери **5 — Замерить**. Увидишь, сколько стало процессов, служб и занятой памяти.
11. Теперь ставь свои программы: браузер, Steam, Discord и т. д. Часть из них Nova может поставить сама: список `installApps` в config.json или раздел «Программы» в конструкторе.

## Если Windows блокирует Nova

- **«Windows защитила ваш компьютер»** — нажми **Подробнее → Выполнить в любом случае**. Так Windows реагирует на любые программы без платной цифровой подписи.
- **«Интеллектуальное управление приложениями заблокировало…»** или Nova пишет про **«ограниченный режим»**. Это функция Smart App Control на свежей Windows 11: она пропускает только программы с платной подписью.
  1. Сначала удали распакованную папку, разблокируй архив (галочка «Разблокировать» в свойствах, шаг 5) и распакуй заново.
  2. Если не помогло, Smart App Control можно выключить: «Безопасность Windows → Управление приложениями и браузером → Параметры интеллектуального управления приложениями → Выкл.». Защитник Windows и остальная защита продолжат работать. Но включить его обратно можно только переустановкой Windows — решай сам.

## Если что-то пошло не так

- **Отменить Nova:** запусти Nova.cmd → **3 — Отменить последний запуск** → перезагрузи компьютер.
- **Точка восстановления:** нажми Win+R, введи `rstrui`, нажми Enter и выбери точку «Nova: перед изменениями».
- **Удалённые приложения** (Погода, Новости и т. п.) можно поставить заново из Microsoft Store.
- Не получается? Сделай фото экрана с ошибкой. Лог каждого запуска Nova лежит в `C:\ProgramData\Nova\logs`.
