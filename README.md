# Nova

**Твоя Windows. Без лишнего.**

Nova — бесплатный инструмент с открытым кодом для Windows 10 и 11. Он убирает рекламу, слежку и мусорные приложения, включает тёмную тему и игровые настройки. Ты сам выбираешь, что менять, — и в один клик можешь всё вернуть.

> Nova **не содержит Windows**, не раздаёт её образы и ничего не активирует. Это набор настроек, который запускается на твоей обычной, лицензионной Windows.

## Что умеет

| Раздел | Что делает |
|---|---|
| Приватность | минимум телеметрии, без рекламного ID и истории действий, выключены Copilot и Recall, Bing убран из поиска |
| Без рекламы | никаких «советов» в «Пуске», самоустанавливающихся приложений, рекламы OneDrive |
| Без мусора | удаляет предустановленные приложения: новости, погоду, пасьянсы, Clipchamp, Teams и другие |
| Интерфейс | тёмная тема, полное меню по правому клику, видимые расширения файлов, панель задач без виджетов |
| Игры и скорость | игровой режим, без Game DVR, планирование GPU, оптимизация игр в окне; по желанию — без энергосбережения процессора и «Целостности памяти» |
| Система и фон | отключает лишние фоновые службы и скрытые задачи сбора данных; по желанию — SysMain, индексацию поиска, печать, Bluetooth, Xbox, «только обновления безопасности» |
| Оформление Nova | свои обои, золотой цвет акцента, Nova в «Параметры → О системе» |
| Замер | считает процессы, службы, задачи и память до и после — честные цифры на твоём ПК |
| Голос | «Нова, сверни все окна», «Нова, выключи компьютер», свои бинды. Распознаёт речь прямо на компьютере (Vosk), без интернета: звук никуда не уходит |
| Замер FPS | средний FPS и просадки (1% low) в твоей игре до и после Nova через PresentMon от Intel. Если разница меньше разброса между замерами, Nova честно скажет «разницы нет» |
| Безопасность | показывает план до изменений, точка восстановления, резервная копия и отмена в один клик. Предохранитель: Nova не может выключить антивирус, брандмауэр, контроль учётных записей, SmartScreen или обновления — такая настройка просто не пройдёт проверку |

Всего 54 настройки (37 включены по умолчанию, остальные — по желанию), полный список с описаниями — в [`src/tweaks.json`](src/tweaks.json).

**Чем Nova отличается от AtlasOS и похожих сборок:** не нужно переустанавливать Windows — Nova работает с уже установленной системой, и любой запуск отменяется одной кнопкой, без переустановки.

## Как запустить

> Ставишь Windows с нуля? Пошагово, от флешки до готовой системы: [`docs/CLEAN-INSTALL.md`](docs/CLEAN-INSTALL.md).

1. Скачай архив Nova ([прямая ссылка](https://github.com/vezin0v0-cmyk/my-project/archive/refs/heads/claude/hello-973j4n.zip) или кнопка «Скачать бесплатно» на [сайте](https://vezin0v0-cmyk.github.io/my-project/docs/)) и распакуй в любую папку.
2. Дважды кликни **`Nova.cmd`** и разреши запуск от имени администратора.
3. Вверху меню Nova покажет **проверку системы**: версия Windows, не ждёт ли она перезагрузки после обновлений, хватает ли места. Подробности — пункт **6**.
4. В меню выбери **1 — Посмотреть, что изменится**. Это ничего не меняет.
5. Если всё устраивает — **2 — Применить настройки**, потом перезагрузи компьютер.
6. После перезагрузки — **5 — Замерить: было → стало**, чтобы увидеть разницу в процессах, службах и памяти.
7. Хочешь проверить FPS? **7 — Замерить FPS в игре**: сделай замеры до Nova и после, в одной и той же сцене. Честно о том, чего ждать: по независимым тестам похожих сборок прибавка обычно в пределах нескольких процентов, а на мощных ПК её может не быть вовсе. Больше всего выигрывают слабые компьютеры с кучей фоновых программ.

Если Windows покажет «Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае**. Так Windows реагирует на любые программы без платной цифровой подписи.

> Совет: в первый раз попробуй Nova на виртуальной машине (например, в бесплатном VirtualBox). Так безопаснее всего посмотреть, как всё работает.

## Голосовые команды

Запусти **`NovaVoice.cmd`** (или пункт **8** в меню Nova). В первый раз Nova скачает бесплатный движок распознавания [Vosk](https://alphacephei.com/vosk/) и русскую модель (~60 МБ, контрольные суммы закреплены).

Говори **«Нова, …»**:

| Скажи | Что будет |
|---|---|
| «Нова, сверни все окна» / «покажи рабочий стол» | все окна свернутся; «Нова, верни окна» — обратно |
| «Нова, закрой окно» | закроется окно, которое сейчас впереди |
| «Нова, закрой все окна» | через 15 секунд закроются все окна — программы спросят сохранить |
| «Нова, выключи компьютер» / «перезагрузка компьютера» | через 15 секунд; **«Нова, отмена»** отменяет |
| «Нова, громче» / «тише» / «выключи звук» | громкость |
| «Нова, заблокируй компьютер», «сделай скриншот», «открой стим» | понятно 🙂 |

- Без слова «Нова» команды не выполняются — голос из игры или Discord ничего не выключит.
- Распознавание идёт на компьютере, без интернета. Звук никуда не отправляется и не сохраняется.
- Свои команды («бинды») — в файле [`voice.json`](voice.json): фраза → встроенное действие, программа/ссылка (`run`) или сочетание клавиш (`keys`, например `win+shift+s`). Если модель не знает какое-то слово, Nova Голос скажет, что его заменить.

## Как настроить под себя

Всё в одном файле — [`config.json`](config.json). Пункт **4** в меню Nova открывает его в Блокноте.

```json
"tweaks": {
  "dark-theme": true,
  "taskbar-left": false,
  "mouse-acceleration-off": true
}
```

- `true` — включить, `false` — не трогать. В примере: тёмная тема включается, «Пуск» остаётся по центру, ускорение мыши выключается.
- `removeApps` — какие приложения удалить.
- `installApps` — какие программы поставить через winget (id программ можно найти на [winget.run](https://winget.run)).
- `createRestorePoint` — создавать ли точку восстановления Windows перед изменениями.

Если ошибёшься в файле (например, забудешь запятую), Nova ничего не изменит и сообщит об ошибке в файле.

## Безопасность и отмена

- Перед изменениями Nova **показывает план**: что изменится и как было.
- Создаёт **точку восстановления Windows**.
- Записывает, как было, в `C:\ProgramData\Nova\backups`. Пункт **3 — Отменить последний запуск** возвращает всё точно в исходное состояние.
- Лог каждого запуска — в `C:\ProgramData\Nova\logs`.
- После применения в «Параметрах» Windows и в Edge может появиться надпись «Некоторыми параметрами управляет ваша организация». Так Windows показывает любые настройки, сделанные через политики, — это нормально. После отмены надпись пропадёт.
- Удалённые приложения автоматически не возвращаются — их можно поставить заново из Microsoft Store.
- Nova не трогает Edge и Microsoft Store: без них ломаются другие программы.
- Запускай Nova из своей учётной записи администратора: настройки интерфейса применяются к тому пользователю, от имени которого она запущена.

## Для разработчиков

```
Nova.cmd             запуск по двойному клику (просит права администратора)
config.json          что включать — правит пользователь
src/Nova.ps1         меню и сценарии: просмотр, применение, отмена
src/Nova.psm1        движок: реестр, службы, питание, приложения, резервные копии
src/tweaks.json      описание всех настроек
src/NovaVoice.ps1    голосовые команды; NovaVoice.psm1 — распознавание (Vosk) и действия
voice.json           голосовые команды и свои бинды
tests/Lint.ps1       синтаксис, кодировка, JSON, PSScriptAnalyzer
tests/Test-Nova.ps1  применяет все настройки и проверяет, что отмена возвращает систему точно как было
docs/index.html      сайт проекта
docs/app.html        вход, регистрация с кодом из письма и личный кабинет с конструктором сборки
docs/AUTH-SETUP.md   как включить настоящие аккаунты и письма с кодом (Supabase)
docs/email/          шаблон письма с кодом подтверждения
docs/vendor/         библиотека Supabase (MIT), загружается только когда аккаунты включены
supabase/avatars.sql хранилище фото профиля: каждый меняет только своё фото
docs/mockup.html     кликабельный макет будущей программы с окнами (установка и Nova Центр)
tools/sync-site-data.py  переносит список настроек из программы в конструктор на сайте
```

Запуск без меню:

```powershell
.\src\Nova.ps1 -Mode Preview          # посмотреть
.\src\Nova.ps1 -Mode Apply -Yes       # применить без вопросов
.\src\Nova.ps1 -Mode Undo -Yes        # отменить последний запуск
.\src\Nova.ps1 -Mode Check            # проверить, готова ли система
.\src\Nova.ps1 -Mode Fps              # замер FPS в игре (60 секунд)
```

**Как добавить настройку.** Добавь объект в `src/tweaks.json` (`id`, `category`, `title`, `description`, `actions`) и строку с её `id` в `config.json`. Типы действий: `registry`, `service`, `powerScheme`, `hibernate`. Отмена работает автоматически: перед изменением Nova записывает прежнее значение. После этого запусти `python tools/sync-site-data.py`, чтобы настройка появилась в конструкторе на сайте (CI проверяет, что это не забыли).

**Тесты.** При каждой отправке кода GitHub Actions запускает проверки на настоящей Windows: линтер, применение всех настроек с проверкой отмены и режим просмотра. Скрипты сохраняются в UTF-8 с BOM — иначе Windows PowerShell 5.1 покажет русский текст кракозябрами.

## Сайт

Сайт проекта — `docs/index.html`. Чтобы опубликовать его бесплатно: **Settings → Pages → Deploy from a branch → `main` / `docs`**. Ссылки на донаты и канал меняются в начале скрипта на странице (объект `SITE`).

**Личный кабинет** (`docs/app.html`) — вход, регистрация с кодом из письма, профиль (своё фото, имя, «о себе», цвет) и конструктор сборки: выбираешь настройки и скачиваешь готовый `config.json`.

Аккаунты работают через [Supabase](https://supabase.com) (бесплатный тариф): он хранит пользователей, пароли в зашифрованном виде и отправляет письмо с 6-значным кодом. Сайт уже подключён к проекту Supabase `nova`: его два публичных ключа записаны в объекте `AUTH` в начале скрипта `docs/app.html`. Письма уходят через Gmail. Как настроить всё заново или поменять почту-отправителя — в [`docs/AUTH-SETUP.md`](docs/AUTH-SETUP.md). Шаблон письма — [`docs/email/confirm-signup.html`](docs/email/confirm-signup.html). Если очистить ключи в `AUTH`, кабинет вернётся в демо-режим: код показывается прямо на странице, а данные хранятся только в браузере.
